# Курсовая работа: Интеграция с API самолетов ✈️

Проект представляет собой консольное приложение для получения, фильтрации и сохранения информации о самолетах, находящихся в воздушном пространстве выбранной страны.

## 🛠 Технологии
* Python 3.14
* Библиотека `requests` (для работы с API)
* `pytest` и `pytest-cov` (для тестирования и оценки покрытия)

## 🌍 Используемые API
1. **Nominatim (OpenStreetMap)** — для получения географических координат (boundingbox) страны.
2. **OpenSky Network** — для получения информации о самолетах в заданных координатах.

## 📂 Структура проекта
* `main.py` — точка входа, интерактивное меню для пользователя.
* `src/` — исходный код:
  * `api.py` — классы для работы с API (наследование, абстракция).
  * `aeroplane.py` — модель самолета (инкапсуляция, валидация, магические методы сравнения).
  * `file_saver.py` — класс для сохранения данных в JSON (с защитой от дублей).
* `data/` — папка для хранения JSON-файла с данными.
* `tests/` — тесты (28 шт., покрытие > 80%).
* `htmlcov/` — сгенерированный HTML-отчет о покрытии тестами.
