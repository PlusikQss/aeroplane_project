# Курсовая работа: Поиск информации с подключением БД 🗄️✈️

Проект представляет собой консольное приложение для сбора, хранения и поиска информации о самолетах. Данные получаются из открытых API (OpenSky Network, Nominatim) и сохраняются в реляционную базу данных PostgreSQL для выполнения сложных аналитических запросов.

## 🛠 Технологии
* Python 3.14
* Библиотека `requests` (для работы с API)
* СУБД `PostgreSQL` и `psycopg2-binary` (для работы с базой данных)
* `python-dotenv` (для безопасного хранения доступов)
* `pytest` и `pytest-cov` (для тестирования)

## 🎯 Основной функционал (Работа с БД)
Для выполнения задания реализован класс `DBManager` (в `src/db_manager.py`), который содержит методы для поиска и анализа информации:
* `get_countries_and_aeroplanes_count()` — выводит список стран и количество самолетов в их пространстве (запрос с `JOIN`).
* `get_all_aeroplanes()` — выводит список всех самолетов с информацией о стране.
* `get_avg_speed()` — вычисляет среднюю скорость всех самолетов (`AVG`).
* `get_aeroplanes_with_higher_speed()` — находит самолеты, летящие быстрее средней скорости (подзапрос).
* `get_aeroplanes_with_keyword()` — поиск самолетов по части позывного (оператор `ILIKE`).

## 🗄 Структура Базы Данных
В БД `aeroplanes_db` созданы две связанные таблицы:
1. **`countries`** (id, name) — справочник стран.
2. **`aeroplanes`** (id, icao24, callsign, velocity, altitude, country_id) — данные о самолетах (внешний ключ `country_id`).

## 📂 Структура проекта
* `main.py` — точка входа, интерактивное меню (API, JSON, БД).
* `src/` — исходный код:
  * `api.py` — классы для работы с API (наследование, абстракция).
  * `aeroplane.py` — модель самолета (инкапсуляция, валидация, магические методы сравнения).
  * `file_saver.py` — класс для сохранения данных в JSON (с защитой от дублей).
  * `db_manager.py` — класс для работы с PostgreSQL (основная логика БД).
* `tests/` — тесты (покрытие > 70%).
* `.env` — файл с секретными данными для подключения к БД (добавлен в `.gitignore`).
* `.env.example` — шаблон для настройки переменных окружения.
